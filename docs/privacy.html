Vaultix Browser 隐私政策

生效日期：2026-11-19 · 最近更新：2026-11-19

一句话版本：这个扩展不收集你的数据、不做统计、不投放广告，也不会把凭证发到我们控制的任何服务器。 它只是把你已有的 Bitwarden / Vaultwarden 与 KeePassXC 密码库接到浏览器表单上。

1. 我们是谁、这个扩展做什么

Vaultix Browser（以下简称"本扩展"）是一个本地运行的浏览器凭证填充器。它的唯一用途是： 在浏览器中查找、填充和保存你自己的密码库条目。项目源码公开于 GitHub 仓库。 本扩展由个人开发者维护，不隶属于 Bitwarden 或 KeePassXC 项目。

2. 我们收集哪些数据

我们不收集、不上传、不分享任何个人数据给第三方。本扩展没有账号系统、没有统计 SDK、没有广告、没有远程配置。具体说明：

  • 主密码：只在内存中用于派生密钥，绝不写入磁盘、绝不上传到任何服务器、绝不写入日志。
  • 明文凭证：仅在浏览器扩展进程的内存中流转，用于填充表单或写回你自己的密码库；不落盘、不出现在日志。
  • 会话数据：临时会话令牌与解密结果保存在 chrome.storage.session（内存态，关闭浏览器即失效）。
  • 本地配置：服务地址、邮箱、锁定时间、默认保存目标等非敏感设置保存在 chrome.storage.local，仅存于你这台设备。
  • 页面信息：内容脚本只在需要填充/保存时读取当前页面表单的字段类型和已输入的值，并通过扩展内部消息传给后台进程；不发送给任何外部服务器，也不记录访问历史。

3. 数据发送到哪里

  • Bitwarden / Vaultwarden：仅与你自己在设置页配置的服务地址通信，用于登录、同步和写回凭证。请求内容按 Bitwarden 协议加密，请求体不含明文密码。
  • KeePassXC：通过本机 keepassxc-proxy 以 Native Messaging 与本机的 KeePassXC 通信，不经过网络。
  • 无其他目的地：本扩展没有analytics端点、遥测、崩溃上报或远程日志。

4. 权限说明

  • activeTab / scripting：仅在你点击扩展图标后，向当前标签页注入填充脚本。
  • storage：保存上述本地非敏感配置与内存会话态。
  • optional_host_permissions：对 Bitwarden 服务地址与当前站点按需申请，用于发起 API 请求和注入脚本；不会在安装时一次性索取全部站点权限。
  • nativeMessaging：连接本机 KeePassXC 代理。
  • clipboardWrite：在你点击"复制密码"时写入剪贴板，并在 30 秒后自动清空。
  • contextMenus / notifications / offscreen：提供右键菜单、状态提示与剪贴板超时清理。

5. 安全设计

明文凭证与主密码永不写入磁盘；会话态不跨浏览器重启保留；日志只输出错误码和脱敏后的域名（eTLD+1）， 不输出完整 URL、查询参数、用户名、令牌或密码。内容脚本与页面上下文隔离，页面脚本无法读取扩展内存中的凭证。

6. 数据处理方式变更

若未来版本改变上述数据处理方式，我们会先更新本隐私政策，并在扩展更新说明中明确告知。 你也可以随时在 GitHub 仓库查看源码与提交记录，核对实际行为。

7. 你的选择

你可以随时在浏览器扩展管理页卸载本扩展；卸载后本地配置随扩展数据一并删除。 你密码库中的条目始终由你自己的密码库管理，本扩展不持有副本。

8. 联系方式

如有隐私相关问题，请通过 GitHub Issues 提交。我们不使用专属邮箱收集个人信息。
