# 06 · 填充引擎

> P3 实现说明。代码入口：`src/content/`；UI 见 `src/ui/`。

## 1. 字段识别

`detectFields()` 遍历普通 DOM 与所有 `shadowRoot`，按 `type` / `name` / `id` / `autocomplete` 分类为
`username` / `password` / `totp`。每类只取第一个字段，避免把密码灌进"确认密码"框。
`observeFields()` 用 MutationObserver 监听动态插入（SPA 场景），150ms 防抖后通知 background。

## 2. 填充纪律（S-4）

只做两件事：写 `input.value`，派发 `input` 与 `change` 事件。
禁止 `innerHTML`、`data-password`、`window.__vaultix` 等任何页面 JS 可读的凭证载体；
content script 运行在隔离世界，消息来自扩展自身。

## 3. 双源结果呈现

popup 只认 `CredentialItem` + `source`（E-2），不 import 适配器。
`ambiguous === true` 时显示轻量提示，不弹模态框、不阻塞默认填充（D-02）。
按钮：填用户名 / 填密码 / 填 TOTP / 复制密码（复制走 offscreen，30 秒自动清空，S-5）。

## 4. 测试（T-3 / G7）

`tests/dom-filler.test.mjs`（jsdom）覆盖普通表单、Shadow DOM、动态插入字段、
事件派发次数与"无敏感 DOM 属性"断言。
