# 07 · 锁定与安全

> P3 实现说明。代码入口：`src/core/lock-manager.ts`、`src/background/`。

## 1. 状态机

状态：`locked` / `unlocked` / `suspended`；事件：`UNLOCK` / `LOCK` / `SUSPEND` / `RESUME` / `ACTIVITY`。

- `SUSPEND` 表示 MV3 service worker 被浏览器回收：会话密钥随之消失。
- `RESUME` **不等于解锁**，必须重新 `UNLOCK`（M-6），禁止静默降级为明文缓存。
- 后台超时默认 5 分钟、空闲超时默认 15 分钟，可在设置页调整；`tick()` 每次检查。

## 2. 存储边界（S-1）

| 数据 | 允许位置 | 禁止位置 |
|---|---|---|
| 服务地址 / 邮箱 / KeePassXC 配对公钥 | `chrome.storage.local` | — |
| access token / 对称密钥会话快照 | `chrome.storage.session` | 磁盘 / localStorage |
| 主密码 / 拉伸密钥 / 明文条目 | 仅内存 | 任何存储、日志、遥测 |

日志统一走 `src/shared/logger.ts`，白名单字段 + eTLD+1 域名脱敏（S-2）；
遥测 / 错误上报默认关闭，现阶段完全未实现（S-7）。

## 3. 剪贴板

MV3 service worker 无剪贴板权限，复制请求转交 offscreen document 写入，
默认 30 秒后写入空串清空（S-5），用户配置的 TTL 仅影响该次复制。

## 4. 测试（T-4）

`tests/lock-manager.test.mjs` 覆盖初始锁定、显式锁定、回收后强制重新解锁、
后台超时与空闲超时（含活动重置计时）。
